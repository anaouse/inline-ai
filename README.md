# Inline AI MVP

在当前编辑器中写下 `~prompt`，将文本光标放在 prompt 末尾，按 `Alt+\`，让 AI 结合上下文生成正文并替换这段 prompt。

## 启动

在项目根目录配置 `.env`，字段见 `.env.example`。终端模式，按 `Ctrl+C` 退出：

```bash
uv run inline-ai
```

托盘模式（无控制台，右键托盘图标退出）：

```bash
uv run inline-ai --tray
```

## 打包 exe

```bash
bash build.sh
```

输出 `dist/inline-ai.exe`。这个 exe 无控制台窗口，双击运行后常驻托盘，右键托盘图标选“退出”关闭。把 `.env` 放在 exe 同目录。

## 使用

1. 在支持 `Ctrl+Shift+Home/End`、`Ctrl+C/V` 的文本编辑器中输入内容。
2. 输入 `~`，接着写指令，例如 `本文为英语基础教学，~给出一段A与B打招呼的对话`。
3. 把文本光标放在指令末尾，不要选中文本。
4. 按下并松开 `Alt+\`。
5. 等待替换完成。期间不要切换窗口、移动光标或输入内容。

光标前的最后一个 `~` 到光标之间的内容就是指令，光标位置相当于闭合标记。程序复制光标前后的文本，以 `<caret>` 标记光标位置，调用 `deepseek-flash`，再用退格删除 `~` 到光标之间的内容并粘贴回答。客户端只在启动时创建一次。

## MVP 限制

- 以光标前最后一个 `~` 作为指令起点，因此指令内容里不能再出现 `~`。
- 会覆盖剪贴板，不保存原来的内容。
- 快捷键和光标操作按 Windows 常见文本编辑器实现，不保证所有编辑器兼容。
- 一次只处理一个请求。请求期间请保持编辑位置不变。
- 网络错误、空回答或回答超过 12800 token 时不执行替换。
- 仅做语法检查，实际快捷键、API 调用和打包由用户运行验收。
